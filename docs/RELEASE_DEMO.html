Một hành trình, sáu thành viên

Trang About hiển thị hồ sơ thành viên, nhiệm vụ, file phụ trách và nội dung đóng góp; người xem có thể mở cửa sổ chi tiết bằng JavaScript.

Trải nghiệm

  • Sáu thẻ thành viên tạo từ dữ liệu.
  • Nút mở chi tiết, chuyển thành viên trước/sau.
  • Điều hướng bàn phím và hỗ trợ reduced motion.

Thiết kế

  • Giới thiệu mục tiêu dự án và công nghệ.
  • Bố cục co giãn theo màn hình.
  • CSS riêng trong assets/css/about.css.

Checklist trước khi phát hành

Chỉ gắn v1.0.0 sau khi đã xác minh

  1. Review và merge các PR; bảo đảm các trang chính có nội dung.
  2. Chạy python tools/check_links.py và sửa lỗi.
  3. Merge release candidate vào main; tạo và push tag v1.0.0.
  4. Bật GitHub Pages, kiểm tra URL công khai và chạy link checker với --base.
  5. Lưu ảnh minh chứng vào docs/images/; cập nhật README, CHANGELOG và báo cáo.

Không ghi “đã phát hành” cho tới khi tag và deployment hoạt động thật.
